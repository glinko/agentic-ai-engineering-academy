# Agentic AI Engineering Academy

[English](README.md) · Русский

Проект распространяется по [лицензии MIT](LICENSE): разрешены использование, изменение, распространение и продажа копий при сохранении уведомления об авторских правах и текста лицензии. Сторонние зависимости сохраняют собственные лицензии.

В редакторе **Tab** добавляет отступ в четыре пробела, **Shift+Tab** убирает один уровень отступа, в том числе для выделенных строк. Чтобы перейти к следующему элементу клавиатурой, нажми **Escape**, затем **Tab**.

По умолчанию платформа открывается на английском. Переключатель English / Русский находится в шапке; выбор сохраняется. Код, подсказки, история и прогресс общие для обоих языков. В репозитории подготовлена новая двуязычная версия; ранее развёрнутый LAN-экземпляр автоматически не обновляется.

Работающий MVP интерактивной платформы: **5 уроков на русском, 15 упражнений, 15 исполняемых примеров и 49 проверок**. React + TypeScript + Vite, CodeMirror 6, настоящий Python 3.13 через Pyodide 0.28.3 в Web Worker.

Развёрнутый экземпляр в локальной сети: **http://192.168.88.122:8090/**. Backend: http://192.168.88.122:8090/api/health. Документация API: `/api/docs`.

## Запуск frontend

Требуется Node.js 22.12+ (проверено с 24.19) и pnpm 11. При отсутствии pnpm можно использовать npm: `npm install`, `npm run dev`.

```sh
pnpm install
pnpm dev
```

Открыть http://localhost:5173. Перед запуском скрипт копирует Pyodide из установленного npm-пакета в `public/pyodide/`. Python, WASM и стандартная библиотека обслуживаются локально: CDN для выполнения кода не нужен. Первая установка зависимостей требует интернет. Шрифты Google необязательны: при отсутствии сети работает системный fallback.

```sh
pnpm build
pnpm preview
```

Сборка находится в `dist/`. Локальный preview использует порт 4173. В frontend нет API-ключей; backend не обязателен для прохождения уроков.

## Как учиться

1. Открой первый урок и прочитай краткую теорию.
2. Запусти три примера и посмотри вывод Python.
3. Перейди к практике, измени код в редакторе.
4. **Run** запускает код; **Check** проверяет его на разных входных данных.
5. При ошибке изучи traceback или сравнение ожидаемого и полученного результата. Подсказки раскрываются последовательно, разбор — после успешного решения.
6. Реши контрольную без подсказок. После всех трёх заданий откроется следующий урок.

**Reset** восстанавливает стартовый код, сохраняя историю и факт освоения. Уроки можно повторять. Переключение темы доступно внизу меню. На телефоне меню открывается кнопкой в шапке.

## Сохранение

В localStorage сохраняются версия схемы, код, просмотренная теория, подсказки, последние 100 попыток каждого задания, результаты тестов, время активной практики и дата первого повторения. Время учитывается интервалами по 10 секунд, только в видимой вкладке практики; это приблизительная метрика активности. Первый интервал повторения — один день; автоматическая очередь 1/3/7/14 дней отложена.

Прогресс привязан к браузеру и **origin**: `localhost:5173` и `192.168.88.122:8090` хранят разные данные. Аккаунтов, серверной синхронизации и автоматического переноса между устройствами пока нет. При ошибке записи отображается предупреждение. Очистка данных браузера удаляет прогресс.

## Проверки

```sh
pnpm test
pnpm test:content
pnpm test:e2e
```

- Unit: жизненный цикл Worker, timeout/cancel/retry, полнота результатов, сериализация прогресса, повреждённое хранилище, структура контента.
- `test:content`: запускает все 15 эталонных решений и 49 тестов в настоящем Pyodide; отдельно проверяет неправильный ответ, SyntaxError и ValueError.
- E2E: Chrome, настоящие Worker и WASM; запуск примера, верные/неверные ответы, синтаксис, исключение, бесконечный цикл, повторное выполнение, Reset, подсказки, история, перезагрузка, мобильное меню и отсутствие горизонтального переполнения.

E2E используют установленный Google Chrome. Если Chrome отсутствует, установить Chromium командой `pnpm exec playwright install chromium` и убрать `channel: 'chrome'` в `playwright.config.ts`. Скриншоты проверки сохраняются в `test-results/`.

## Backend и развёртывание

FastAPI обслуживает готовую сборку и три вида API: health, метаданные программы, заглушки интерфейса наставника. Произвольный Python на сервер **не отправляется и не исполняется**. Заглушки наставника возвращают HTTP 501; неизвестные операции — 404.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
pnpm build
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8090
```

На `192.168.88.122` приложение работает от пользователя `user`, без root и Docker. Пользовательский сервис `agentic-academy.service` слушает адрес локальной сети, порт 8090. У пользователя уже включён systemd linger. Код релиза — `~/agentic-academy/releases/`, активная версия — symlink `~/agentic-academy/current`, окружение — `~/agentic-academy/.venv/`. Ключи не входят в артефакт или исходный код.

```sh
systemctl --user status agentic-academy
journalctl --user -u agentic-academy -n 50
systemctl --user restart agentic-academy
```

Обновление: собрать frontend, упаковать только `dist`, `backend`, `deploy`; загрузить архив по SSH; распаковать в новый каталог `releases/<version>` и выполнить `bash <release>/deploy/install.sh <version>`. Скрипт сохраняет путь предыдущего релиза, устанавливает зависимости в выделенное окружение, фиксирует их версии в `requirements.lock.txt` релиза и перезапускает сервис.

Откат к известному каталогу: `ln -sfn /home/user/agentic-academy/releases/<previous-version> /home/user/agentic-academy/current`, затем `systemctl --user restart agentic-academy`. Релизы автоматически не удаляются. В текущем MVP API не хранит пользовательские данные, миграции БД не нужны. Для обновлений зависимостей сверяй lock-файл: общее venv не обеспечивает отдельную версию зависимостей для каждого релиза.

Это LAN-развёртывание без TLS и авторизации. Для внешнего доступа потребуется отдельная настройка HTTPS, доступа и серверного хранения прогресса.
