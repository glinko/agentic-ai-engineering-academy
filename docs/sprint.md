# Sprint 01 scope

[Русский](ru/sprint.md)

The first sprint implements React/TypeScript/Vite scaffolding, a modular Python engine, versioned progress, a responsive interface, and the first five connected Python lessons. Each lesson has three runnable examples and three exercises, including an independent checkpoint. The final exercise combines earlier concepts into a research report.

The roadmap spans 26 weeks and 12 stages. Remaining stages are plans, not pre-generated course content. Current metrics report actual exercise completion. The proposed 20% theory / 40% practice / 30% projects / 10% explanation score is not used because independent project and explanation assessment does not yet exist.

English is now the default interface and content language, with persistent Russian switching. Both languages share stable exercise IDs and progress.

## Next steps

1. Complete the MVP as a learner and revise explanations based on real mistakes.
2. Add functions, files, exceptions, pytest, Git, and a CLI link library.
3. Add progress export/import, accounts, and review scheduling at 1/3/7/14 days.
4. Add HTTP/FastAPI and async tasks after designing a separate isolated runner.
5. Connect a backend-only tutor adapter to a local or cloud LLM; validate generated exercises automatically before publishing them.

Publish new content after validating the MVP rather than generating the full course in advance.
