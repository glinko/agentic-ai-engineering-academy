# Спринт 01

## Технический план

1. React/TypeScript/Vite, декларативный контент и отдельный модуль прогресса.
2. Dashboard, Lesson, Exercise, адаптивный интерфейс и темы.
3. Самостоятельно размещённый Pyodide в dedicated Web Worker; отмена, дедлайн, JSON-результаты.
4. Пять связанных уроков, три примера и три упражнения на каждый.
5. Unit, проверка эталонов в реальном Python, E2E в браузере.
6. FastAPI host на 192.168.88.122; отдельный venv, user systemd, versioned releases.

## Результат

Реализованы переменные/типы, строки, условия, циклы, списки/словари. Пятнадцатое задание объединяет предыдущие темы в отчёт исследователя. Остальные этапы курса представлены только roadmap, без массовой генерации контента.

Метрики MVP показывают честное количество пройденных упражнений. Просмотр теории записывается отдельно. Веса 20% теория / 40% практика / 30% проекты / 10% объяснение пока не используются: независимой оценки проектов и защиты решения ещё нет, поэтому сводный «профессиональный рейтинг» был бы вводящим в заблуждение.

## Следующие спринты

1. Пройти MVP на себе, собрать реальные ошибки и отредактировать теорию/границы тестов.
2. Функции, файлы, обработка ошибок, pytest, Git и CLI-хранилище ссылок.
3. Аккаунт и экспорт/импорт прогресса; очередь повторений 1/3/7/14 дней.
4. HTTP/FastAPI и async, после проектирования отдельного изолированного runner.
5. Backend-адаптер наставника: локальный OpenAI-compatible endpoint или облачный провайдер, без ключей в браузере. Динамические упражнения — только после настоящей автоматической валидации.

Следующие темы публикуются после проверки качества MVP, а не заранее ради объёма курса.
