# Agentic Academy v0.1.0 — Windows and Ubuntu MVP

The first installable release of Agentic AI Engineering Academy.

- 5 Python lessons, 15 runnable examples, and 15 exercises with independent public tests.
- English/Russian switching, saved drafts and progress, light/dark themes.
- Real Python in a browser Web Worker with a five-second execution limit.
- Tab/Shift+Tab indentation in the editor; Escape then Tab moves focus out.
- MIT project license, with bundled third-party license notices.

## Windows 10/11 x64

Download **agentic-academy-v0.1.0-windows-x64.zip**, extract the entire ZIP, and double-click **agentic-academy/start.cmd**. A local server opens the app in your browser. No separate Python, Node.js, Docker, or administrator rights are required. Keep the console open; Ctrl+C stops the server.

## Ubuntu

```sh
curl -fsSL https://raw.githubusercontent.com/glinko/agentic-ai-engineering-academy/v0.1.0/install/ubuntu.sh | bash
```

Requires Python 3.10+, curl and sha256sum (Ubuntu 22.04/24.04/26.04). No pip dependencies, npm, Docker, or root access. The installer validates the archive checksum and starts a user systemd service when available.

Default address: **http://127.0.0.1:8090/**. On a remote Ubuntu host, use an SSH tunnel or explicitly set `ACADEMY_HOST=0.0.0.0` for trusted-LAN access. `ACADEMY_PORT=8091` selects another port.

The Ubuntu tarball can also be extracted and launched with `bash start.sh`. SHA256SUMS is attached for archive verification.

See [installation, updates, rollback and service controls](https://github.com/glinko/agentic-ai-engineering-academy/blob/v0.1.0/docs/distribution.md).

## Verification

The Windows ZIP was extracted into a path containing spaces and started through its bundled launcher/runtime. All four browser scenarios passed against that package, including real Pyodide execution, timeout recovery, language switching, and Tab indentation. Six dependency-free server tests and 11 frontend unit tests passed. On Ubuntu 26.04, installation, repeat installation, checksum rejection, occupied-port detection, and service rollback were verified.

## Scope

This is a personal-learning MVP. Only the first five Python lessons are available; the full 26-week course remains a roadmap. The AI tutor, secure server assessment, accounts, and cross-device synchronization are not connected. Progress stays in the browser and follows its hostname/port. Windows ARM64/32-bit and macOS packages are not included.
