# Циклы

**Цикл (loop)** повторяет действие: обрабатывает сообщения, складывает расходы или проверяет результаты инструментов. `for` перебирает элементы последовательности.

```python
total = 0
for tokens in [12, 8, 20]:
    total += tokens
print(total)  # 40
```

`total` — накопитель (accumulator). Создай его **перед** циклом. Если обнулять внутри, предыдущий результат потеряется. Пустой список не выполнит тело цикла ни разу.

## Условие внутри цикла

```python
slow_count = 0
for latency in [120, 1500, 1000]:
    if latency > 1000:
        slow_count += 1
```

Отступы выражают вложенность. `range(3)` даёт числа 0, 1, 2. `while condition` повторяет блок, пока условие истинно; обновляй значения, от которых оно зависит.

## Досрочная остановка

`break` завершает весь цикл, `continue` переходит к следующей итерации. Для бюджета проверь следующий расход **до** прибавления. Если он не помещается, используй `break`: пропуск и поиск дешёвого элемента изменит смысл алгоритма.

Бесконечный цикл остановит лимит тренажёра. После остановки окружение будет пересоздано, чтобы следующее выполнение работало независимо.
