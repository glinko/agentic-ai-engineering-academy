# Строки и операции

**Строка (string, str)** хранит текст: инструкцию, URL, сообщение. Строки записывают в одинарных или двойных кавычках. Они неизменяемы: методы возвращают новое значение.

```python
raw = "  RESEARCH  "
command = raw.strip().lower()
print(command)  # research
```

`strip()` убирает пробельные символы с краёв, `lower()` приводит к нижнему регистру, `upper()` — к верхнему. Методы можно вызывать цепочкой. Пробелы внутри текста `strip()` сохраняет.

## Форматирование

**f-string** — строка с префиксом `f`. Выражения в фигурных скобках заменяются их значениями.

```python
agent = "Research"
count = 3
message = f"Agent {agent}: {count} tasks"
print(message)
```

`len(text)` возвращает количество символов. `text[0]` — первый символ, `text[:5]` — первые пять. Обращение по индексу к пустой строке вызывает `IndexError`. Внутри строки `\n` означает перевод строки.

## Порядок операций

Чтобы измерить длину очищенного запроса, сначала вызови `strip()`, потом `len()`. Проверяй пустой ввод: после очистки строка из пробелов станет пустой.
