# Условия и логика

Агенту нужно решать, можно ли вызвать инструмент, повторить запрос или запросить подтверждение. **Условие (condition)** — выражение со значением `True` или `False`.

```python
if balance >= cost:
    action = "run"
else:
    action = "stop"
```

После условия ставится двоеточие. Вложенный блок выделяется одинаковым отступом — обычно четырьмя пробелами. `elif` добавляет ещё одну ветку. Выполняется только первая подходящая ветка.

## Сравнения

`==` проверяет равенство, `!=` — неравенство, `<`, `>`, `<=`, `>=` сравнивают величины. `=` присваивает значение; не путай его с `==`. Диапазон можно записать как `200 <= status < 300`.

## Логические операторы

`and` требует выполнения обоих условий, `or` — хотя бы одного, `not` меняет логическое значение на противоположное.

```python
allowed = is_authenticated and (not is_dangerous or approved)
```

Скобки явно показывают, как сгруппированы правила. Проверяй границы: ровно достаточный баланс, код 299 и код 300. Именно на границах часто скрываются ошибки.
