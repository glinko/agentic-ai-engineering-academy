# Списки и словари

**Список (list)** — упорядоченная изменяемая коллекция. **Словарь (dictionary, dict)** хранит значения по ключам. Вместе они описывают сообщения, задачи и результаты поиска.

```python
tools = ["search", "fetch"]
tools.append("memory")
message = {"id": 1, "priority": "high"}
print(message["id"])
```

`append()` добавляет элемент в конец и возвращает `None`. Не записывай результат этого метода обратно в переменную списка.

## Копии и ссылки

`updated = tools` связывает два имени с одним списком. Изменение одного видно через другое. `tools.copy()` создаёт отдельную поверхностную копию. Для вложенных изменяемых объектов этого не всегда достаточно.

## Безопасное чтение словаря

`message["priority"]` вызовет `KeyError`, если ключ отсутствует. `message.get("priority")` вернёт `None`; можно задать значение по умолчанию: `message.get("priority", "normal")`.

```python
urgent_ids = []
for message in messages:
    if message.get("priority") == "high":
        urgent_ids.append(message["id"])
```

Цикл сохраняет исходный порядок. В контрольной работе ты объединишь переменные, строки, условия, циклы и коллекции в отчёт для будущего Research Assistant.
