# Переменные и типы данных

Любой агент работает с данными: именами инструментов, лимитами запросов и флагами доступа. **Переменная (variable)** — имя, связанное со значением. Создай её с помощью `=`.

```python
agent_name = "Research"  # str — строка
max_steps = 5             # int — целое число
temperature = 0.7         # float — дробное число
is_active = True          # bool — логическое значение
```

Python определяет тип автоматически. `type(max_steps)` покажет тип, а `print(max_steps)` выведет значение. Имена чувствительны к регистру: `Agent` и `agent` — разные переменные. Используй понятные имена в стиле `snake_case`.

## Арифметика и преобразование типов

Операторы `+`, `-`, `*`, `/` выполняют обычные вычисления. `/` возвращает дробное число, `//` — деление с округлением вниз, `%` — остаток. Скобки задают порядок действий.

API часто возвращает числа строками. `int("42")` превращает строку в целое число, `float("0.5")` — в дробное, `str(42)` — обратно в строку. Сложение строк соединяет их: `"12" + "8"` даёт `"128"`, а не `20`.
